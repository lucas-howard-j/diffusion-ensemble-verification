# Lorenz-63 Testbed (Archived)

This directory contains an early exploratory testbed applying the DDPM to the 3D Lorenz-63 chaotic system. It was abandoned because the L63 system does not exhibit the CRPS–VS decoupling that is the central finding of the paper.

The active testbed is **Lorenz-96** (40D). See `../lorenz96/` for the published controlled experiments.

Code is preserved here for reference only.
